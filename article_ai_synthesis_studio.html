AI Synthesis Studio: How to Use It

General › Results and Reports | Updated: 2025-12-26

The AI Synthesis Studio in Userology helps you make sense of your user research using AI. It allows you to either:

  • Chat with your research data to explore insights informally, or

  • Build a report to document findings in a structured way.

This guide explains where to access the AI Synthesis Studio and walks you through both workflows step by step.

Accessing the AI Synthesis Studio

  1. Log in to your Userology workspace.

  2. Navigate to AI Synthesis Studio.

  3. From the Synthesis Workspace, select the project or sessions you want to analyze.

  4. Use the option to Bring in your research sessions.

Once selected, your data is loaded into the AI Synthesis Studio and you can choose how you want to work with it.

Two Ways to Work in AI Synthesis Studio

Inside the Studio, you will see two main options:

  • Chat with Data – for exploration and discovery

  • Build Report – for creating a structured synthesis output

You can switch between these at any time.

Path A: Chat with Data

Best for:
Quick exploration, asking questions, and understanding patterns in your research without creating a formal report.

How Chat with Data Works

1. Start Chat with Data

  • From the AI Synthesis Studio, click on Chat with Data.

  • The chat interface opens with your selected research data loaded.

2. Ask Questions

You can interact with the AI in two ways:

  • Text Input
    Type your question in the message box.

  • Voice Input
    Click the Microphone icon to speak your question instead of typing.

You can ask questions like:

  • "What problems are users facing?"

  • "What feedback did users give about onboarding?"

  • "Summarize key themes from these sessions."

3. Review AI Responses

  • The AI answers using only your selected research data.

  • Responses are shown directly in the chat.

4. Verify with Source References

  • AI responses include numbered citations (for example, [1], [2]).

  • Hover over a citation to open a video mini-player.

  • This lets you watch or listen to the exact moment from the session where the insight came from, without leaving the chat.

5. Share the Chat (Optional)

  • You can generate a shareable link for the chat.

  • This allows others to view the conversation and insights.

Note: Chat insights are not automatically added to reports. Chat is meant for exploration and discussion.

Path B: Build Report

Best for:
Documenting findings, sharing insights with stakeholders, and creating a structured output from your research.

How Build Report Works

1. Start Build Report

  • From the AI Synthesis Studio, click Build Report.

2. AI Generates the Report

  • The AI analyzes your selected research data.

  • It generates a structured report that summarizes key insights and patterns.

The report is created automatically based on the data you selected.

3. Review the Report

  • You can read through the generated report inside the Studio.

  • This view is intended for reviewing and sharing insights, not manual editing inside the Studio.

4. Download the Report

  • You can download the report as an .html file.

  • This file can be:

    • Opened in a browser

    • Shared with stakeholders

    • Used for documentation or presentations

Chat with Data vs Build Report: When to Use What

If you want to… Use
Explore ideas and patterns Chat with Data
Ask ad-hoc research questions Chat with Data
Verify insights with session clips Chat with Data
Create a structured summary Build Report
Share findings as a document Build Report

Summary

The AI Synthesis Studio supports two clear workflows:

  • Chat with Data helps you explore and understand your research by asking questions and verifying insights with real session evidence.

  • Build Report helps you turn that understanding into a structured report that can be downloaded and shared.

You can move between both at any time, depending on whether you are exploring or documenting insights.
